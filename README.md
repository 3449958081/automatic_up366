# 天学网答案提取（C# 原生版）

用于读取「天学网」电脑客户端下载到本地的试题数据：自动解密、提取题目与答案，并提供**自动回答**、**搜题对答案**、**扫描提取**与**抓包拉题库**四大功能。

## 一、软件简介

- **C# 原生内核 + 原版精致界面**：截图 / OCR / 匹配 / 点击全在进程内完成（P/Invoke + 内置 Tesseract 本地 OCR，随安装包自带中英语言包、无需联网），界面为原版 WebUI 视觉（现代扁平卡片设计）经 **WebView2 内嵌** 1:1 移植，无浏览器标签、无 Node、无 PowerShell 依赖，性能与原生度最优。
- **setup.exe 一键安装**：单个安装包把应用本体装到 Program Files，允许各类数据文件存在；**天学网客户端与程序本体在文件夹尺度上分立存放**，互不干扰。
- **首次自选客户端目录**：首次点【启动客户端】时，如检测不到客户端，会自动下载官方安装包并弹窗引导你选择目录安装，省去手动寻找客户端的功夫。
- 运行数据（题库索引、导出、抓包日志、配置）统一存放在 `%LOCALAPPDATA%\TxwExtract`，卸载程序不残留用户数据。

### 本版特性

1. **setup 一键安装**：单个安装包安装应用本体（默认 `C:\Program Files\天学网答案提取`），程序自包含 .NET 8 运行时，目标机无需安装任何环境。
2. **客户端目录分立**：天学网客户端与程序本体在文件夹尺度上分开存放，互不干扰；首次使用由你自选客户端目录。
3. **首次自动安装客户端**：首次点【启动客户端】时若检测不到，会自动下载官方安装包并弹窗引导选择目录静默安装。
4. **自动回答 · 最低置信度**：可选高/中/低三档，决定「什么样的匹配才会被点击」，选择自动保存，下次沿用。
5. **多方案解密自检、扫描基线增量标记、题库自动扩充**等。
6. **高精度点击逻辑**：自动把客户端提到最前台再操作；蓝色胶囊按钮按像素定位（不依赖底栏文字）；点击后确认选项框变蓝才继续；同屏多题逐个作答。

## 二、文件组成

**安装后：**

```
C:\Program Files\天学网答案提取\   —— 应用本体（只读）
    天学网答案提取.exe               —— 主程序
    *.dll 等                         —— 自包含运行时与组件
```

**运行数据（自动生成，卸载程序不删除）：**

```
%LOCALAPPDATA%\TxwExtract\
    config.json        —— 应用偏好（minConf、intervalMs、clientExe、scanDir）
    launcher.json      —— 客户端位置记录（首次自选后自动写入）
    installer\         —— 自动下载的客户端安装包
    auto\export\       —— 扫描提取导出的 JSON / HTML 报告
    keys.json          —— 自定义解密凭据（添加过才会出现）
    baseline.json      —— 扫描基线（标记新旧课程用）
```

以上均为自动生成的数据文件，删除不影响程序本身。天学网客户端安装在你首次自选的位置（如 `D:\Up366StudentFiles`），与程序本体完全分立。

## 三、安装与启动

1. 运行 `天学网答案提取_Setup_v1.6.7.exe`，一路下一步（默认安装到 `C:\Program Files\天学网答案提取`），可选创建桌面快捷方式。**程序需要管理员权限运行**——天学网客户端以管理员运行，只有同权限才能向其注入自动点击；**启动时会弹 UAC 提框，点「是」确认即可**（无论从桌面图标还是开始菜单启动都不会再报「错误代码 740」）。
   - 若点了「否」也能打开，但自动回答的点击会被系统拦截。
2. 安装完成自动运行；程序为**自包含**版本，目标机无需预装 .NET 运行时。
3. 界面依赖 **Microsoft Edge WebView2 运行时**（Windows 11 自带；Windows 10 一般随 Edge 自动安装，缺失时安装包会提示，可从微软官网免费获取）。
4. 关闭：点窗口右上角关闭按钮即可（托盘无驻留）。
5. 卸载：设置 → 应用 → 天学网答案提取，或开始菜单卸载项。

> 若界面空白：需要 Microsoft Edge WebView2 运行时。Windows 11 自带；Windows 10 请到微软官网搜索「WebView2 Runtime」下载安装后重开本程序。

## 四、首次启用 · 客户端目录自选与自动安装

触发条件：`%LOCALAPPDATA%\TxwExtract\launcher.json` 不存在、运行中的进程与常见目录均找不到客户端。

流程：

1. 点【启动客户端】→ 弹窗询问是否自动下载官方安装包（约 250 MB）。
2. 弹出目录选择框，让你自选客户端安装目录（建议选客户端专用目录，与程序分立，例如 `D:\Up366StudentFiles`）。
3. 下载官方安装包到 `%LOCALAPPDATA%\TxwExtract\installer\`。
4. 优先静默安装到所选目录（自动尝试 NSIS `/S /D=` / Inno `/VERYSILENT /DIR=` 静默参数），失败则弹安装向导（把安装位置改为所选目录）。
5. 完成后自动定位客户端 exe 并写入 `launcher.json`，下次启动直接使用，无需再手动寻找。
- 安装完成后可用【清理安装包】删除已下载的安装包，释放空间（安装包约 250 MB，装完即无用）。

- 客户端与程序本体**分立存放**：程序安装在 Program Files，客户端安装在你自选的目录，互不覆盖。
- 不想自动下载？手动安装客户端后，在 `config.json` 中写入 `"clientExe": "D:\\up366\\client\\up366.exe"` 即可。
- 想换客户端位置？删除 `launcher.json` 后重试即可重新选择。

## 五、功能说明

窗口内有四个选项卡（默认打开主打功能「自动回答」）。

### 选项卡一：自动回答（主打功能）

> **两种作答引擎可切换**：
> - **DOM 直连（推荐）**：经 Chrome DevTools Protocol 直连客户端页面节点判题作答，直接读取页面内嵌的参考答案并按真实选项字母点选（选项顺序被打乱也能命中；题目没内嵌答案时改为查本工具抓到的答案库），不受界面改版/字号/配色影响，**无需选择窗口**。使用前需先**完全退出客户端**（含托盘），再点页面内「启动客户端」按钮，由本工具以**调试模式**重启客户端；
> - **屏幕视觉 OCR（兼容）**：截图识别 + 模拟点击的旧方案，需手动选择客户端窗口，客户端正常运行即可，无需调试开关。
>
> 两种模式下，「无痕下载接管」都会自动启动以抓取并更新题库答案。

1. 点「启动客户端」拉起天学网客户端（若未安装会自动引导下载安装），在客户端内登录并打开一次测试。
2. 点「刷新窗口」并在下拉中选择目标窗口（默认自动选中天学网窗口，已排除本工具自身窗口）。
3. 设好【最低置信度】下拉（见下）。
4. 点「开始自动回答」：按设定间隔轮询界面：
   - 界面无变化 → 只做 OCR，不做任何操作（听力播放期间不干扰）；
   - 检测到变化 → 匹配本地题库，置信度不低于所选门槛才点击（日志写明每次点击的置信度）；
   - 每次点击后会重新截图确认「选项框已变蓝」，确认成功后才自动向下滚动推进；
   - 滚到底出现「下一页」自动点击翻页（按蓝色胶囊像素定位，不依赖底栏文字）；
   - 一路作答到最后一页（页面不再出现「下一页」按钮）且作答完全时 → 自动点击「提交」（按「提交」二字模糊识别；提交后出现成绩页自动停止）；
   - 出现「得分/成绩/正确率」结果页 → 自动停止；
   - 也可随时点「停止」。
5. 日志与最近识别文字实时显示，方便核对。

> 精确度优先：宁可不点也不乱点；题库来自本地已下载试卷，多打开几套命中率更高。

**最低置信度**

| 档位 | 行为 |
|---|---|
| 高 | 仅「高置信」（题干 + 选项双命中）才点击 |
| 中（默认） | 「高置信」+「中置信」（题干或选项命中其一） |
| 低 | 全部处理，含「未命中」与兜底模糊匹配（命中率最高、准确率最低） |

选择保存在 `%LOCALAPPDATA%\TxwExtract\config.json`（下次启动自动沿用），运行日志会记录每次点击的置信度。

### 选项卡二：搜题对答案

1. 把试卷文本（题号 + 题干 + 选项）粘贴到输入框，或点「从图片识别(OCR)」导入试卷长图自动识别填入。
2. 点「开始匹配」，自动在本地题库中查找相同或相似题目。
3. 结果分三档：高置信 / 中置信 / 未命中；答案按内容匹配，天学网打乱选项顺序也能对上（字母+文字同时显示）。
4. 可按「最低置信度」过滤显示。

### 选项卡三：扫描提取

1. 目录框默认指向 `D:\Up366StudentFiles\resources`（客户端数据目录），也可点「浏览…」自选。
2. 点「扫描」列出已下载的课程/绘本，含「新/旧」标记（可点「记为基线」重置基线，之后只标记新增内容）。
3. 勾选课程，点「解密导出所选」，生成 JSON（结构化）与 HTML（可打印）报告到 `%LOCALAPPDATA%\TxwExtract\auto\export\`。

### 选项卡四：无痕下载接管（抓题库答案，推荐）

> 这是抓答案的主路径，**全自动、客户端零设置、零文件改动、零感知**；抓到的答案自动并入「自动回答」题库，无需重启即可命中。

1. 入口在「自动回答」页下方的「无痕下载接管」卡片。点「启动接管」即可（点「开始自动回答」时也会自动启动）。
2. 原理：启动时在本机做一处**临时**的下载链路接管（停止时自动还原并刷新解析缓存），让客户端的课程包下载经过本机；包经过时解析出答案并自动并入「自动回答」题库。**全程不修改客户端的任何文件与设置。**
3. 抓到的答案**永久缓存**在本机（`%LOCALAPPDATA%\TxwExtract\minicloud\answers.json`，清空前不丢，题库越抓越大）；可点「清空答案缓存」一键清除（不影响客户端课程缓存与扫描题库）。
4. 若客户端报「下载出错」，点「停止接管」即还原临时接管，客户端恢复正常。
5. 「清理课程缓存」可删除 flipbooks，重新打开课程即触发重新下载，用于刷新抓到的内容。

> 「抓包拉题库」选项卡与「无痕下载接管」**共用同一套接管实现**（状态与答案完全共享），任选其一操作即可。

### 数据解密（内置，无需操作）

- 解密全程在本地完成，不联网、不上传任何数据。
- 内置自检与自动修复：正常情况下无需任何操作；若某天数据解不开，可在「设置/密钥」里点一键自检修复，结果下次启动自动生效。

## 六、config.json 可配置项（可选）

路径：`%LOCALAPPDATA%\TxwExtract\config.json`

```json
{
  "minConf": "mid",
  "intervalMs": 20000,
  "clientExe": "D:\\up366\\client\\up366.exe",
  "scanDir": "D:\\Up366StudentFiles\\resources"
}
```

| 字段 | 作用 |
|---|---|
| `minConf` | 最低置信度：`high` / `mid`（默认） / `low` |
| `intervalMs` | 自动回答轮询间隔（毫秒），默认 20000；**可在界面上自由填写（单位：秒），最短 5 秒**（OCR 识别一轮通常需数秒） |
| `clientExe` | 客户端 exe 完整路径（存在则跳过自动探测/安装） |
| `scanDir` | 客户端数据目录（扫描/搜题用，留空自动从客户端配置推导） |

## 七、常见问题（FAQ）

- **安装时被杀软拦截？** 本地自编译程序，添加信任即可（自签名程序常见误报）。Windows SmartScreen 可点「仍要运行」。
- **界面空白/无法显示？** 需安装 Microsoft Edge WebView2 运行时（Win11 自带；Win10 缺失时到微软官网搜索「WebView2 Runtime」下载安装）。
- **点不动 / 点击偏移？** 程序按物理像素坐标点击（PerMonitorV2），请保持目标窗口缩放为 100% 或确保系统缩放一致；另外点击/滚轮前程序会自动把客户端提到最前台。
- **OCR 无文字？** 程序内置 Tesseract 中英 OCR（随安装包自带语言包），若识别异常请确认 `{安装目录}\tesseract\tessdata\` 下存在 `chi_sim.traineddata` 与 `eng.traineddata`。
- **首次启动没有自动下载安装客户端？** 说明检测到了已存在的客户端（或已有 `launcher.json`）。需要重装可删除 `launcher.json` 后重新点【启动客户端】。
- **扫描不到课程？** 确认天学网客户端已经下载过内容（打开过试卷）；若换了数据目录，请在扫描页修改目录路径后重新扫描。
- **提示解密失败？** 多为客户端数据格式更新所致。请在「设置/密钥」里点一键自检修复（程序会重新推导并验证），仍失败请反馈。
- **客户端下载失败？** 多为上次异常退出后，临时接管设置未及还原所致。关闭窗口会自动还原，下次启动也会自动自愈；也可点一下「停止接管」立即还原。
- **接管已生效但客户端仍报错？** 可点「停止接管 → 启动接管」重建本地链路，并**重启客户端**清掉它的错误缓存。仍异常请反馈日志。
- **搜题命中率不高？** 题库来自本地已下载的试卷。请在客户端中多打开几套试卷，数据落盘后题库自动扩充，命中率会随之提高。
- **抓不到答案？** 点「启动接管」后**重启天学网客户端**（让它重新走接管链路），再打开/下载课程，答案会自动解析并缓存。已缓存内容不会重复下载。
- **会不会破坏原数据？** 不会。本工具只读取和解密，从不修改客户端数据目录。
- **杀软报毒？** 本地自编译程序，仅自动装客户端时联网访问天学网官方服务器；添加信任即可。
- **卸载后会有残留吗？** 程序文件随卸载删除；`%LOCALAPPDATA%\TxwExtract` 中的运行数据（题库导出、配置等）默认保留，可手动删除。

## 八、开发 / 二次构建

- 源码：`src\`（C# / .NET 8，WinForms + WebView2 界面 + 内置 Tesseract OCR + P/Invoke）。
- 界面：`web\index.html`（原版 WebUI，改动即时生效——运行时优先读外置文件，缺省回退嵌入资源）。
- 构建发布：`dotnet publish -c Release -r win-x64 --self-contained true -o publish`（需 .NET SDK 8）。
- 安装包：`ISCC.exe installer.iss`（Inno Setup 6），产物在 `dist\`。
- 注意：`publish\` 不含 `tesseract\` 与 `web\`（由 `installer.iss` 单独打包仓库内对应目录），直接跑 `publish\` 里的 exe 会 OCR 全挂。
- 内置自测开关（开发/排查用，不影响正常使用）：
  - `--banktest`：用真实客户端数据建库并打印统计（验证解密与题库）。
  - `--keyscan [all]`：解密链路自检（重新推导并验证解密能力）。
  - `--mctest`：接管闭环自测（用临时文件替代真实系统设置，因此**无需管理员权限**）。
  - `--mcselftest [下载ID]`：接管端到端自测——走一遍完整下载链路，验证转发与答案解析。
  - `--cdptest <端口>`：CDP 连通性自测（枚举页面目标 → 连接 → 读帧树 → ping）。
  - `--dpiinfo`：打印 `Screen.Bounds` 与 `SM_CXSCREEN` 口径，排查点击偏移。
  - `--certcheck [renew]`：运行环境依赖项期限体检；加 `renew` 强制执行一次临期检查。
  - `--certtest [端口]`：起临时 TLS 服务（60 秒）验证链路，供严格校验客户端验证。
  - `--mcparse <文件>`：解析下载包并打印解析结果。
- 工程笔记：`docs\工程笔记.md`——实现方法论与踩坑记录（通用工程向）。
- 静态审计器：`python _researchudit.py`（可加 `--verbose`）——检查三登记、参数透传、"未知即拒绝"兜底、单位混用、配置字段跨界共用、重复 BOM、publish exe 版本资源。**改完代码先跑它。**
- 一键体检脚本：`python _research\healthcheck.py`（可加 `--live <下载ID>` 真发一次下载请求）——出现"接管不生效/下载失败/取不到数据"时先跑它。
