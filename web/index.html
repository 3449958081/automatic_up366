使用须知
功能说明
  • 自动回答（主打）：两种引擎 —— DOM 直连（推荐）直连客户端页面判题作答，直接读页面内嵌的参考答案、选项顺序被打乱也能命中；题目没内嵌答案时改为查本工具抓到的答案库。屏幕视觉 OCR（兼容）截图识别 + 模拟点击。
  • 搜题对答案：粘贴试卷文本或导入长图 OCR，本地题库匹配，结果分高 / 中 / 未命中。
  • 扫描提取：扫客户端数据目录，勾选课程导出 JSON + 可打印 HTML 报告。
  • 导出位置：下载的 JSON / HTML / 作文报告固定保存到该目录。可在扫描提取页的「导出位置」卡片里直接输入路径、点「浏览…」选择，或点「恢复默认」用回系统下载文件夹下的 TxwExtract。下载完成后右上角会提示实际保存路径，可一键打开所在文件夹。
  • 抓包拉题库 / 无痕下载接管：同一套接管实现，任选其一；抓到的答案自动并入题库。
  • 作文报告：客户端里报告页被马赛克挡住（权益为试用型时会出现）也能提取正文 —— 只做运行时去遮罩，导出 .txt / .html，不改动客户端文件。需用调试模式启动客户端并先打开报告页。
要做的
  • 启动时 UAC 弹框点「是」，否则自动点击会被系统拦截。
  • 用 DOM 直连前，先完全退出客户端（含托盘），再从页内点「启动客户端」。
  • 首次使用按提示自选客户端安装目录（之后自动记住）。
  • 抓题库：点「启动接管」后重启客户端，再打开 / 下载课程。
  • 出问题时：界面空白 → 装 Microsoft Edge WebView2 运行时后重开；解密失败 → 「密钥管理」按 ① → ② → ③ 依次尝试；客户端报"下载出错" → 点「停止接管」即还原；被杀软拦截 → 添加信任即可。
不用做的
  • 不用改系统代理、不用手动改任何系统设置 —— 程序自动接管，停止 / 关窗自动还原。
  • DOM 直连不用选窗口。
  • 不用手动装客户端 —— 检测不到会引导自动下载安装。
  • 不用手动清缓存 —— 抓到的答案自动缓存并长期可用。
  • 不用担心弄坏客户端 —— 只读取和解密，不改客户端任何文件。
